# GraphPlotter — Лабораторная работа 1. Визуализация данных

Приложение на C# / Windows Forms (.NET 8) для построения графиков функций,
заданных **аналитически** (формулой) или **таблично** (из текстового файла).

## Как собрать и запустить

Нужен установленный .NET SDK 8.0 (или новее): https://dotnet.microsoft.com/download

```bash
cd GraphPlotter
dotnet run
```

Либо откройте `GraphPlotter.csproj` в Visual Studio 2022+ и запустите (F5).
Приложение — обычный WinForms-проект, работает только под Windows.

## Возможности и соответствие требованиям задания

- **Графический интерфейс.** Переключатели вверху окна позволяют выбрать
  форму задания функции: «Аналитическая функция» или «Табличная функция».
- **Начало координат по умолчанию — в центре области построения.**
  При запуске и после каждого нового построения (`ResetView`) центр экрана
  соответствует точке (0, 0); оси Ox (горизонтальная, независимая переменная)
  и Oy (вертикальная, зависимая переменная) рисуются со стрелками, делениями
  и подписанными значениями.
- **Масштабирование.** Колесо мыши увеличивает/уменьшает масштаб относительно
  точки под курсором. Шаг сетки и число знаков после запятой в подписях осей
  пересчитываются динамически («красивые» шаги 1/2/5·10ⁿ), поэтому при
  сильном увеличении значения корректно отображаются вплоть до разряда
  десятитысячных (0.0001) и мельче — ограничения на глубину масштабирования
  практически нет.
- **Смещение центра координат.** Перетаскивание левой кнопкой мыши по полю
  графика панорамирует вид. Кнопка «Сбросить вид» возвращает исходное
  положение и масштаб.
- **Аналитическая функция.** Поле ввода принимает выражения в стандартной
  математической записи: `+ - * / ^`, скобки, неявное умножение (`2x`,
  `3(x+1)`), элементарные функции `sin, cos, tg/tan, ctg/cot, arcsin, arccos,
  arctg/arctan, sqrt, ln, lg (log10), exp, abs` и константы `pi`, `e`.
  Пример: `sin(x) + 0.5*cos(2*x)`, `x^2 - 3*x + 2`, `1/x`, `sqrt(4 - x^2)`.
  Разрывы функции (деление на 0, область определения) отображаются как
  разрывы линии графика, а не как ошибка.
- **Табличная функция.** Кнопка «Загрузить файл...» открывает диалог выбора
  текстового файла. Файл — два столбца чисел (x и y), разделённых **любым**
  стандартным разделителем: пробелом, табуляцией, точкой с запятой (можно и
  их комбинацией/повторением). Количество строк произвольно. Десятичным
  разделителем может быть как точка, так и запятая. Пустые строки и строки,
  начинающиеся с `#` или `//`, пропускаются. После загрузки график
  автоматически масштабируется так, чтобы все точки поместились в область
  просмотра; данные соединяются линией и отмечаются точками.
  Пример файла — `sample_data.txt` в этой папке.

## Структура проекта

| Файл                     | Назначение                                                        |
|--------------------------|--------------------------------------------------------------------|
| `Program.cs`             | Точка входа                                                        |
| `MainForm.cs`            | Главное окно: выбор режима, ввод формулы/файла, статус-бар         |
| `GraphControl.cs`        | Область построения: сетка, оси, масштаб/панорамирование, отрисовка |
| `ExpressionEvaluator.cs` | Разбор и вычисление аналитического выражения f(x)                 |
| `sample_data.txt`        | Пример табличных данных для тестирования                          |

## Дальнейшее развитие

Приложение спроектировано так, чтобы `GraphControl` (координатные
преобразования, сетка, оси, масштаб) можно было переиспользовать в
последующих лабораторных работах без изменений — достаточно передавать
новую функцию/данные через свойства `Function` и `TablePoints`.
